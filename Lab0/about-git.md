# Лабораторная работа 0

## 1. Чем ветка отличается от копии папки с проектом?

Ветка - это указатель на коммит внутри общего репозитория `.git`, а не отдельная
папка. Все ветки делят одну историю, поэтому переключение между ними мгновенное.
Копия папки - независимый набор файлов, не связанный с историей.

## 2. Что произойдёт с историей, если удалить папку проекта, но сохранить `.git`?

История сохранится — все коммиты лежат в `.git`, а не в рабочих файлах. Файлы
можно восстановить командой `git checkout`. Пропадут только незакоммиченные
изменения.

## 3. Зачем нужен Pull Request, если можно коммитить сразу в `main`?

PR нужен для проверки изменений до попадания в `main`: коллеги смотрят код,
оставляют комментарии, запускаются тесты. Это защищает основную ветку от ошибок.
Прямые коммиты в `main` удобны только в одиночной работе.
